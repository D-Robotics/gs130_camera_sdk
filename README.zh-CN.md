# 项目已迁移

GS130 Camera SDK 已由 **RDK Stereo Camera SDK** 接替：

**https://github.com/D-Robotics/RDK-Stereo-Camera-SDK**

[English](README.md)

## 为什么新建项目

产品线从 GS130WI / GS130W 扩展到 GS130WI V2、RDK Stereo A1 与 A1P。旧名字不再覆盖整个产品族：
"GS130" 里的 GS（全局快门）、130（像素尺寸）、W（广角）、I（IMU）编码了具体规格，
型号一多就不再成立。

## 有什么变化

新项目不再编码规格：

- SDK 名：**RDK Stereo Camera SDK**
- 原生库：`libdstereocam`
- 命令行工具：`dsc`
- 软件包：`dstereo-cam`
- 版本线：从 0.1.0 重新开始

## 本仓库的状态

停在最后一个版本 **0.1.2-Alpha**，仅作历史保留；`develop` 分支已删除，不再接受提交。
